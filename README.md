# PlasticMarket — Sitio web

Fabricación de productos industriales de plástico y caucho termoplástico en Chile.

Sitio 100% estático (HTML + CSS + JS plano, sin frameworks ni build). Listo para GitHub Pages, Vercel, Netlify o cualquier hosting estático.

## Archivos
- `index.html` — Página de inicio
- `productos.html` — Catálogo de productos
- `contacto.html` — Contacto y ubicación (Santiago / Miami)
- `logo.png`, `logo-leaf.png` — Logos
- `hero-video.mp4`, `matriceria-video.mp4`, `quienes-somos-video.mp4` — Videos
- `certificado-fl.jpg` — Certificado
- `productos-fotos/` — Fotos de productos
- `logos-clientes/` — Logos de clientes

## Uso
Subir todo el contenido a un repositorio y activar GitHub Pages apuntando a la raíz (`index.html` como entrada), o desplegar directamente en Vercel/Netlify sin configuración adicional.
